# Cycle Navi PWA 0.4

ロードバイク向けの地点検索・自転車経路作成・GPSナビ・天気／風・標高／勾配表示アプリです。フレームワーク、APIキー、ビルド用パッケージのインストールは不要です。

## 使い方

1. 出発地・到着地を検索候補から選ぶか、それぞれの「現在地を設定」を押します。現在地は設定した時点の固定座標です。
2. 必要なら中継地点を追加します（最大5か所）。「サイクリングロード・自転車道を優先」は初期状態で有効です。
3. 「自転車ルートを作成」で順序どおりの経路を取得します。GPXの取込にも対応します。
4. 停止した状態で「ナビ開始」を押し、位置情報を許可します。ナビ中は画面を表示したまま使います。
5. 「一時停止／再開」「終了」で走行を管理し、記録をGPXとして書き出せます。

iPhoneはSafariの共有→ホーム画面に追加、Androidはブラウザメニュー→アプリをインストールからPWAとして使えます。HTTPSで開いてください。

## 自動リルート

- 初期状態で有効です。「自動リルート」をオフにすると元コースの表示だけを続けます。
- GPS精度が良好で、距離が概ね35m以上（精度によって判定距離を調整）の逸脱が8秒継続するとオンラインで再探索します。精度が35mを超える場合は自動再探索を保留します。
- 地点から作成したコースでは、実際に通過した経由地を除き、未通過の中継地点・目的地を順番に残します。通過判定はコース上の進捗と地点までの距離を両方確認します。
- GPXや旧版からのコースでは、前方の復帰地点まで道路経路を計算し、その後の元コースを残します。道路経路と元コースの接続が35mを超えて離れている場合は失敗として扱います。
- 再探索しても走行済みの記録と距離は残ります。更新した経路の残距離・標高解析は再計算します。
- 画面が表示されているときのみ実行し、再試行は60秒以上あけます。1リクエストのみ実行し、終了・休憩・コース変更・元コース復帰後に到着した古い結果は適用しません。
- 圏外・エラー時は元コースを表示して理由を案内し、直線経路で代用しません。コース逆走、複雑な交差、施設内の経由地等の挙動は実走で確認してください。

## ヘッドアップ表示

ナビ開始時は進行方向を上にする設定が有効になります。速度1.5m/s以上ではGPSの進行方向を利用し、取れないときは精度のよい位置間の移動から方位を推定します。角度を平滑化し、停止時は直前の方位を維持します。スマホ本体の向きのセンサーは使用しません。

N↑ボタンで北固定に切替できます。地図全体表示・ドラッグ・標高グラフからの地点確認時は追従を止めて北固定で閲覧し、◎で現在地追従へ戻します。地図タイル・経路・軌跡・現在地マークに同じ回転を適用します。

## サイクリングロード優先

経路サービスはFOSSGISのValhallaです。自転車用コストを使い、優先設定がオンなら `use_roads: 0`、オフなら `0.5` とします。ロードバイク種別、悪路回避の強いペナルティ、階段への強いペナルティを指定します。

これは一般道の通行禁止や、自転車道だけを必ず通る保証ではありません。OSMの自転車通行条件、接続性、路面等の収録状況に依存し、一般道や共用道、必要な接続路も含まれます。最短距離より遠回りになる場合があります。通行止め・現地の標識・路面は実際に確認してください。GPXの本体形状はこの設定では変更せず、復帰経路を計算するときに利用します。

## ヒルクライムと勾配

- コース作成・GPX取込時に標高解析を開始します。旧版の解析は更新時に再取得します。手動の「標高を取得」も使えます。
- 全点に標高のあるGPXはその値を使用し、それ以外はOpen-Meteo Elevation API（Copernicus DEM GLO-90、約90mメッシュ）を利用します。
- 距離に沿って約100m間隔・最大800点で再標本化し、中央値と移動平均で平滑化します。長いコースでは間隔が広がり、勾配は原則200m以上の区間平均となります。
- 地図・標高グラフを勾配で色分けし、獲得標高・下降量・最大上り勾配の概算を表示します。スライダーや坂一覧から地図を確認できます。
- 距離300m以上・獲得標高15m以上の登り区間を抽出し、獲得標高50m以上なら300m未満の短い登りも対象とします。途中の小さな下り（8m未満）や短い平坦部（300m未満）をまとめるため、2%未満の緩い長い上りも対象です。
- **獲得標高50m以上の坂は、開始の約300m前（速度が高い場合は約30秒前を目安に距離を拡大）から、獲得標高と距離を画面・音声で1回案内します。** 音声は「音声で曲がり角・登り坂を通知」がオンで、ブラウザが音声再生に対応している場合に利用できます。音声案内中は競合を避けて通知を待ちます。
- コース出発点がすでに坂の途中の場合や標高の取得失敗・GPS不良時は、開始前の通知ができない場合があります。標高・坂・勾配は推定値で、短い急坂や橋・トンネル等は道路面の実際の値と異なる場合があります。
- 解析結果はコースとともに端末へ保存し、取得後はオフラインでも表示します。

## 天気・風

地点設定またはGPXの出発・中間付近・到着地点について、天気・気温・風向・風速・突風、時間別の降水確率を表示します。手動取得・30秒以上の再取得間隔です。風向は吹いてくる方角、矢印は風が進む方向。m/s・地上10mのモデル推定値で、観測実況・警報ではありません。日本時間の現在推定と今後8時間程度の時間別予報を切り替えます。

## 保存・プライバシー・制約

コース・走行記録・標高解析・通過済み経由地はIndexedDB、地点設定はlocalStorageに保存します。データ削除やOS等によるブラウザ保存領域の消去に備え、走行記録を定期的に書き出してください。

- 地図：OpenStreetMap標準タイル。表示範囲・IPアドレス等が配信元へ送られます。画面に必要な範囲だけ取得し、先読み・一括保存・地図のオフライン配布はしません。
- 検索：Photon。検索ボタンを押したときに検索語を送信し、同一検索をセッション内キャッシュします。
- 経路：FOSSGIS / Valhalla。経路作成時の地点座標、リルート時の現在地・未通過経由地（GPXでは復帰地点）を送信します。`X-Client-Id`を付け、単一リクエスト・最短1.5秒間隔・自動再試行最短60秒に制限します。
- 気象・標高：Open-Meteo。取得対象の地点座標を送信します。標高は100点ずつ最大8回に分けます。無料APIは非商用の個人利用を想定します。
- 走行軌跡全体をアップロードする機能、アクセス解析、アカウント機能はありません。

公共サービスには可用性保証がありません。多数利用・商用化時には、利用条件に合う契約サービスや自己運用基盤、アプリ全体のレート制御へ移行してください。

**画面消灯・アプリ切替中のGPS・記録・音声・リルートの継続は、PWAでは保証できません。** 画面を表示したまま使用してください。画面点灯維持は対応端末・ブラウザのみ利用できます。圏外では保存済みアプリ・コース・記録の表示とGPS追従を使えますが、地図取得・検索・経路探索・気象更新はできません。

## 開発と検証

Node.js 22以降、Python 3を使用します。外部パッケージのインストールは不要です。

```bash
npm test
npm run serve
```

PCは `http://localhost:8080` で確認します。スマホの位置情報・PWAはHTTPSの公開URLで検証してください。自動テストはGPS経路追従、現在地許可／拒否、回転変換、未通過経由地維持、逸脱判定条件、リルート中止・失敗・遅延応答、坂の検出・50m事前案内、外部応答解析を含みます。実走時のGPS・発熱・電池・音声タイミングは実機で確認が必要です。

## GitHub Pages

1. このフォルダの内容をmainブランチへ登録します（`.github/workflows/pages.yml`も含む）。
2. リポジトリの Settings → Pages → Source → GitHub Actions を選びます。
3. mainへのpush後、テスト成功で公開されます。ルートURLから `app/` の本体へ移動します。
4. PWAのキャッシュを更新する際は `app/sw.js` のCACHE版番号を上げてください。更新時のプリキャッシュはHTTPキャッシュを再検証して取得します。更新取得後、開いているアプリ画面をすべて閉じて開き直すと新しい版になります。
