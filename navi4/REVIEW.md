# navi4 1.1 レビュー記録（2026-11-07）

ユーザーの依頼に基づき、アプリ品質と自転車ナビ利用設計の2つの観点を別々のAIレビュアーで検討した。外部の人間の専門家による監修・実走評価ではない。

## 指摘と修正

| 重要度 | 指摘 | 修正 |
|---|---|---|
| 高 | 縦長地図が停止操作を画面外に押し出す | ナビ専用表示で地図のみ可変高、案内・風・計器・操作を同じ画面に配置 |
| 高 | 風HUDが自車・コースを覆う | 地図の外・ナビ内の専用帯に移動 |
| 高 | GPS停止／休憩時に取得対象が出発地へ戻る | 直近有効位置を保持、GPS待ちと取得地点距離を表示 |
| 中 | GPS不良時も古い相対風表示が続く | 精度不良・GPSエラー・更新停止で即時無効化 |
| 中 | 拡大表示中も背後の設定にフォーカスできる | 背景をinertにして専用表示内へフォーカス移動 |
| 中 | PWAの待機中更新に気付けない | 停止中に適用できる更新通知を追加。旧版の初回更新手順を説明 |

主要指摘の修正後、両観点で再レビューした。追加指摘も反映した。

## 検証

- 旧アプリ32件、navi4既存32件、新規10件の合計74件の自動テストが通過。
- 新規検証：アンカー2/3、回転と取得範囲の整合、風の方角・相対方向・無風／欠損値、2分／10分／5kmの更新境界、同時リクエスト、古いコースの遅延応答破棄、圏外・非表示、失敗後の再試行、GPS中断・休憩中の地点保持。

## 限界と次の確認

実機の走行中の日光下視認性・振動・グローブ操作・GPS挙動・電池消費は未測定。「120%」のような定量的な完成度や、全端末での完全性は保証しない。長い案内文・文字拡大・横向きの小画面ではスクロールが必要になる場合がある。安全な場所で端末の表示と操作性を確認する。
