# navi4 自転車ナビ

Cycle Navi 0.4の機能を引き継いだ独立PWAです。

- 出発地・到着地に現在地を設定。中継地点は最大5か所。
- 自転車道優先のルート作成と、未通過の中継地点を保つ自動リルート。
- GPSによる進行方向を上にした表示。
- 標高グラフ、勾配表示、獲得標高50m以上の登り坂の事前案内。
- 天気・風向・風速・突風・時間別予報。
- GPX取込・走行記録出力・端末保存。

## 旧アプリとの分離

元の `app/` は変更せず、このフォルダを別URLで公開します。PWAの名前とスコープ、IndexedDB、localStorage、Service Workerキャッシュは独立しています。旧アプリの地点や走行履歴を自動コピーしません。必要なコースはGPXで読み込んでください。

## 公開・利用

GitHub Pagesの公開ワークフローが `navi4/` を含めて配信します。公開URLをSafari／Chromeで開き、ホーム画面に追加してください。

自動リルートはオンライン・画面表示中に実行します。GPSを伴う実走確認は未実施です。標高・勾配・天気は推定値で、地図の通行条件や現地の標識を優先してください。

経路作成・リルート時には指定地点や現在地をFOSSGIS / Valhallaへ、検索語をPhotonへ、気象・標高の対象座標をOpen-Meteoへ送信します。利用上の詳細・外部サービスの条件は親フォルダのREADMEを参照してください。


## 1.1 ナビ表示の改善

- 縦長の地図と、ナビ開始時に開く専用表示。「通常表示に戻る」で地点設定等に戻れます。地図・風・速度・一時停止／終了を同じ画面に配置します。
- 進行方向が取得できているヘッドアップ追従時、自車を地図の高さの2/3に配置。北固定・全体表示・地図確認時は中央基準です。
- ナビ内の風表示はコース設定時に出発地点、走行時に直近の精度良好なGPS地点を対象に自動取得。10分経過か5km移動で更新、最短2分。GPS不良時は最後の有効地点を保持します。
- 風速はm/s、風向の文字は吹いてくる方角、矢印は風が進む向き。相対風は有効なGPS方位がある場合のみ表示。推定時刻・取得地点までの距離・更新失敗・古さを明示します。地上10mのモデル推定で、路面の実測値ではありません。
- アプリ設計と自転車利用の2系統のAIレビューで問題を洗い出し、修正と再レビューを実施。内容と実測未確認事項はREVIEW.mdを参照。
- 旧1.0からの初回更新は、navi4の全タブとインストール済みPWAを閉じ、開き直してください。1.1以降では待機中の更新を案内し、ナビ終了後に適用できます。

## 1.1.1 終了時の走行距離リセット

「終了」で走行距離を0.0kmに戻し、端末への保存値も0にします。走行記録は残すため、終了後もGPXで書き出せます。一時停止／再開では距離をリセットしません。

## 1.2 音声案内

「音声テスト」と話す速さ・案内音量の設定、ナビ内の消音ボタンを追加。設定は端末内に保存します。日本語読み上げで開始・休憩・再開・終了、曲がり角の予告／直前、GPS不良、逸脱、リルート完了、獲得標高50m以上の坂、終点付近を案内します。終点でも自動終了はしません。曲がり角は形状による推定です。優先度・有効期限で古い案内や重複を抑制し、消音・非表示・コース変更時に待機案内を破棄します。音声テストは案内をオンにします。Web Speech APIを使い、マイクは利用しません。日本語音声・出力可否・音量・画面ロック時の動作は端末に依存します。実機での聴取・実走は未確認です。
