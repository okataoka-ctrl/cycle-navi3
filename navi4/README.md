# navi4 自転車ナビ

Cycle Navi 0.4の機能を引き継いだ独立PWAです。

- 出発地・到着地に現在地を設定。中継地点は最大5か所。
- 自転車道優先のルート作成と、未通過の中継地点を保つ自動リルート。
- GPSによる進行方向を上にした表示。
- 標高グラフ、勾配表示、獲得標高50m以上の登り坂の事前案内。
- 天気・風向・風速・突風・時間別予報。
- GPX取込・走行記録出力・端末保存。

## 旧アプリとの分離

元の `app/` は変更せず、このフォルダを別URLで公開します。PWAの名前とスコープ、IndexedDB、localStorage、Service Workerキャッシュは独立しています。旧アプリの地点や走行履歴を自動コピーしません。必要なコースはGPXで読み込んでください。

## 公開・利用

GitHub Pagesの公開ワークフローが `navi4/` を含めて配信します。公開URLをSafari／Chromeで開き、ホーム画面に追加してください。

自動リルートはオンライン・画面表示中に実行します。GPSを伴う実走確認は未実施です。標高・勾配・天気は推定値で、地図の通行条件や現地の標識を優先してください。

経路作成・リルート時には指定地点や現在地をFOSSGIS / Valhallaへ、検索語をPhotonへ、気象・標高の対象座標をOpen-Meteoへ送信します。利用上の詳細・外部サービスの条件は親フォルダのREADMEを参照してください。
